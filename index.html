        What it makes

        A ready-to-load Isaac Sim OmniGraph extension with one or more Python nodes for the Action Graph or Push Graph. Pick inputs and outputs, download, then write your own logic.

        • .ogn node definitions from the form
        • A Python starting template per node, in the style of the Isaac Sim VS Code template: internal state, then compute() that reads inputs, leaves room for your code and writes outputs
        • Optional execution pins and ROS 2 publisher / subscriber (rclpy) setup

        Why no build?

        Isaac Sim's OmniGraph finds .ogn files inside an extension's Python module folder and generates the node code at startup. This tool writes exactly that layout, so there is no premake or repo build step.

        Tested by loading generated nodes, including Action Graph runs, in Isaac Sim 5.0 and 6.1.

        FAQ

        How do I create a custom Action Graph node in Isaac Sim?

        Load an example here, edit inputs, outputs and code, download the zip, then add its parent folder under Window > Extensions > Settings > Extension Search Paths and enable it.

        Can I change the Python code later?

        Yes, it is yours. Edit Ogn<Node>.py freely; Isaac Sim reloads it automatically. Open the folder here again to change inputs and outputs: your .py is kept as-is and the builder warns if it uses names that no longer exist.

        Does it support ROS 2?

        Yes. Turn on ROS 2 for a node to get a Topic Name input and rclpy publisher or subscriber code using Isaac Sim's ROS 2 bridge.

        Does it support C++ nodes?

        No. C++ nodes must be compiled with the Isaac Sim or Kit build tools. This tool is for Python nodes.

        Is my code uploaded anywhere?

        No. Everything runs in your browser.
